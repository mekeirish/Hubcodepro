# 🔌 Hubcode | Le Repository Manager

> Propulsé par **Mekeirish** • Partie de *The Code Suite*

Hubcode est la tour de contrôle Git de l'écosystème. Il gère la liaison directe, le suivi et la synchronisation de tes fichiers monolithiques locaux vers tes dépôts distants GitHub de manière ultra-simplifiée et transparente.

## 🔮 Interface & Design
*   **Charte Graphique :** `The Code Suite - Strict` (Matte Cyber & Soft UI).
*   **Coloris :** Cartes de dépôts en gris sombre (`#16161a`), repository actif encadré de Violet Électrique. Bouton focal "Push / Sync" en Violet, alertes et loaders en Jaune Cyber.
*   **Layout :** Grille de déploiement (Deployment Dashboard) scannable d'un seul coup d'œil.

## 🚀 Fonctionnalités Clés
*   **Gestion de Token Pure :** Flux local rationalisé. Lecture et écriture directes du GitHub Token dans le `localStorage` en texte brut pour un workflow rapide et sans friction.
*   **Synchronisation One-Click :** Actions de Push, Pull et création de dépôts centralisées géométriquement.
*   **Suivi des Versions :** Visualisation claire de l'état de tes projets distants et détection des fichiers prêts à être synchronisés.
